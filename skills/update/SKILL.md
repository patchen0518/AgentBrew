# AgentBrew Update Skill

Use this skill to keep your tools up to date with their upstream repositories.

## Usage Guidelines

- **Updating Specific Package:** Use `agentbrew update <packageName>` to update one specific tool.
- **Updating Everything:** Use `agentbrew update --all` to sync all installed packages with their remotes.

## Commands

```bash
agentbrew update <packageName>
agentbrew update --all
```
